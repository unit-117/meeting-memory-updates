Meeting Memory 0.3.4

Meeting Memory 0.3.4 improves long-meeting analysis, delivery recovery, and audio capture diagnostics.

- Longer meetings receive analysis time per section. A failed section gets one summary-only retry, then a clearly labeled extractive fallback while later sections continue. Summary headings use readable timestamps.
- Multipart ChatGPT uploads are spaced 90 seconds apart to reduce omitted payloads in cloud task handoffs. Exact exports are retained privately for recovery. Upload acceptance is explicitly distinguished from verified saving in Meetings.
- The meeting menu adds Refresh notes and Retry saving in ChatGPT. Recovery retries keep the original content and cloud deduplication identifiers.
- Automatic capture refreshes the selected app's audio helpers during a call. Silent or near-silent tracks produce a visible capture-quality warning and retain audio. Track labels no longer claim to identify speakers.

A five-part synthetic cloud delivery was verified character-for-character. This does not guarantee every future cloud task succeeds. Actual remote-participant audio capture still requires a consenting live call on this version. No recordings or credentials are included in this release.
